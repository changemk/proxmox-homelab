# Contributing and reuse

This repository primarily documents a personal learning homelab. Before proposing changes, check whether guidance is **confirmed for the original setup** or a **suggested improvement**. Do not describe planned services as deployed.

- Keep examples copyable and avoid hard-coded personal addresses or credentials.
- Cite upstream project documentation for version-dependent commands.
- Do not add screenshots of media libraries, authentication screens, or networking details without a privacy review.
- For significant changes, explain the validation performed and rollback path.

No open-source license has been selected yet. Permission to reuse code or documentation beyond applicable law is not automatically granted.
